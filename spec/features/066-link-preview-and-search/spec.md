# 066 · A link that shows the app, and a site search engines can read

**Status:** done

## What it does

Now that the app lives at its own domain, <https://keireki-craft.eu/>:

- **A shared link shows a card.** Pasted into LinkedIn, WhatsApp, Slack, X or Telegram, the link
  shows a title, one sentence and a picture of the app (the editor with a CV), instead of a bare URL.
- **The app has real icons.** Saved to a phone's home screen it shows the Keireki Craft logo, not a
  screenshot of the page (iOS and Android do not use the SVG favicon).
- **Search engines can read the site.** `robots.txt` lets them in and names the sitemap; the
  sitemap lists the one page; the page names its canonical address.

## Why

The domain was set up on 2026-11-02. Until now the site had only a Spanish `description` and an SVG
favicon: a shared link was a bare URL and the site gave search engines nothing to go on.

## Acceptance criteria

- [ ] The built `index.html` has `og:title`, `og:description`, `og:image` (absolute URL, 1200×630,
      with its width, height and alt), `og:url`, `og:type`, `og:site_name` and
      `twitter:card = summary_large_image`.
- [ ] `<link rel="canonical" href="https://keireki-craft.eu/">`, and the description in English,
      like the README.
- [ ] `apple-touch-icon` (180 px) and PNG icons of 192 and 512 px, drawn from `public/favicon.svg`.
- [ ] `https://keireki-craft.eu/robots.txt` and `/sitemap.xml` answer 200 after the deploy.
- [ ] The images are generated by a script from the built app and the favicon, so they can be redone.
- [ ] `npm test`, `npm run build` and `npm run qa:e2e` pass; the CSP is unchanged.

## Out of scope

- Installing the app and working offline: 067.
- Verifying the domain in Google Search Console or in GitHub: done by the owner.
- A page per language: the app is one page, its language chosen in the browser.
